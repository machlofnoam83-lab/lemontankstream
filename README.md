# lemontankstream

## ⚡ אדיאל גוניון - Adial Gonian

Smart Desktop Assistant inspired by JARVIS & Friday from Iron Man.

See [`adial-gonian/README.md`](adial-gonian/README.md) for full documentation.

### Quick Start (Windows)

```bash
cd adial-gonian
install.bat    # First time: install dependencies
start.bat      # Launch the assistant
```

### Features
- 🎤 Voice activation with wake word "אדיאל גוניון"
- 🗣️ Hebrew speech recognition & synthesis
- 👁️ Live screen awareness (Vision AI)
- 🖥️ Iron Man-style floating HUD (Electron + React)
- 🧠 GPT-4o / Claude AI with vision support
