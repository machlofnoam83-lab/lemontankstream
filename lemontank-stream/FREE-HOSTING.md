## 1. למה האתר הזה לא עולה על Vercel / Netlify / Render

זה לא "עדיף" — זה **לא רץ**, בגלל ארבע דרישות של המערכת:

| דרישה | למה | מה נשבר בלעדיה |
|---|---|---|
| תהליך Node ארוך-חיים | `server.mjs` מריץ את Next.js **בתוך התהליך** + שער אבטחה | serverless מכבה כל בקשה |
| דיסק קבוע | המסד הוא קובץ SQLite מקומי (63 טבלאות) | המסד נמחק בכל פריסה/הפעלה |
| WebSocket | מסיבות צפייה משותפות | serverless לא מחזיק חיבור |
| מנהרה + כותרת סודית | כל שכבת החמקן | פלטפורמות מנוהלות לא נותנות את זה |

**מסקנה:** צריך **שרת** עם דיסק. כלומר VPS — ויש אחד חינמי באמת.

| **Oracle Cloud Always Free** | ✅ **לתמיד** | ✅ 200GB | ✅ **האפשרות הנכונה** |

## 2. אחסון חינם — מה שבאמת חינם

### 🥇 Oracle Cloud — Always Free (ההמלצה)

| משאב | חינם לתמיד |
|---|---|
| מחשב ARM (Ampere A1) | **2 ליבות + 12GB RAM** — קוצר מ-4/24 ביוני 2026 |
| דיסק | 200GB סה"כ |
| **תעבורה יוצאת** | **10TB בחודש** ← הקריטי לאתר וידאו |
| כתובת IP ציבורית | 1 קבועה |

זה השרת היחיד שמחזיק אתר וידאו בלי לשלם. 2 ליבות מספיקות בהחלט — הצוואר
באתר כזה הוא רוחב פס, לא מעבד.

**שני מלכודות שכדאי להכיר:**
- `Out of capacity` — שגיאה נפוצה כשמנסים לפתוח מופע ARM. פתרונות: לנסות אזור
  אחר (ולפתוח את החשבון באותו אזור), לנסות בשעות פחות עמוסות, או **לשדרג לחשבון
  Pay-As-You-Go** — המשאבים ב-Always Free נשארים בחינם, אבל מקבלים עדיפות בתור.
- Oracle **משחזרת מופעים לא פעילים** בחשבונות חינמיים. לכן: האתר הזה חייב לרוץ
  שירות שרץ בעצמו (systemd) — ולא "להפעיל כשצריך".

### 🥈 Google Cloud — e2-micro (חינם לתמיד, אבל הגבלה קשה)

1 ליבה משותפת, 1GB RAM, 30GB דיסק, רק באזורי ארה"ב.
❌ **תעבורה יוצאת: 1GB בחודש** — זה בערך 15 דקות וידאו. מתאים לבדיקות, לא לאתר.

### 🥉 מחשב בבית / לפטופ ישן

אם יש לך מחשב ישן — זה חינם לגמרי, בלי הגבלת תעבורה. בשילוב מנהרת Cloudflare
(סעיף 5) **הכתובת הביתית שלך לא נחשפת בכלל** — השרת יוזם חיבור יוצא, ואין פורט
פתוח בבית. החסרון: שהמחשב כבוי — האתר למטה.

### ב. דומיין בזול — ההמלצה האמיתית

| איפה | סוג | מחיר לשנה |
|---|---|---|
| **gen.xyz** | מספרי (6–9 ספרות) `.xyz` | **~$1** — וגם החידוש |

**בכל שנה**. על 5 שנים זה ₪200 מול ₪350.

### ג. למה זה משנה לאתר שלך ספציפית

זה לא רק כסף — זו **טביעת האצבע**:

| | תת-דומיין חינם (`x.onrender.com`) | דומיין משלך |
|---|---|---|
| מה סורק לומד עליך | מיד: מי הספק, איזו פלטפורמה | כלום — מנהרה מסתירה גם את הספק |
| כמה אתרים חולקים את הדומיין | אלפים | רק אתה |
| קידום וזכירות | אפס | יש |
| CT logs | רשום (כמו כל אתר) | רשום — אבל אין עליו שום מידע נוסף |

**וזו התזכורת הכנה שחזרה גם במדידת האיתוריות:** קיום הדומיין שלך גלוי ממילא
ב-Transparency Logs. מטרת הדומיין שלך אינה להעלים את הקיום — אלא **שלא יהיה עליו
שום מידע שיקשר אותו אלייך או לטכנולוגיה שלך**. תת-דומיין של ספק עושה בדיוק את
ההפך.

## 4. המסלול 100% חינם (₪0) — ומה המחיר

```
Oracle Cloud Always Free          ₪0
Cloudflare (DNS/CDN/מנהרה/R2)     ₪0
דומיין: yourname.dedyn.io         ₪0
──────────────────────────────────────
סה"כ                              ₪0
```

**מה מקבלים:** אתר מלא, HTTPS, מנהרה מוסתרת, חמקן פעיל, אחסון וידאו 10GB ב-R2.
**המחיר:** הדומיין שלך מכיל את שם השירות (`dedyn.io`), כלומר מי שקרא את הדומיין
יודע שהאתר על DNS גרמני חינמי. תוקף שיראה את זה ינסה גם את השאר. רוב הסורקים
לא מחפשים `dedyn.io` — אבל המידע הזה קיים.

**הפשרה המומלצת:** שים את האתר על תת-דומיין חינם **עכשיו** כדי שהוא יעבוד,
וקנה דומיין ב-₪10–40 כשהאתר מתחיל לעבוד. החלפה כזו לוקחת 10 דקות (שינוי
DNS + עדכון `APP_URL`), וסשנים קיימים פשוט יתנתקו פעם אחת.

## 5. ההתקנה — צעד אחר צעד

### שלב 1 — פתיחת שרת חינם ב-Oracle

1. הרשמה ב-`oracle.com/cloud/free` (דורש כרטיס — לחיוב אימות בלבד; משאבי
   Always Free לא מחויבים)
2. **Instance → Create**: Image = Ubuntu 22.04 (ARM), Shape =
   `VM.Standard.A1.Flex`, ‏2 OCPU / 12GB, Boot volume 50GB
3. שמור את מפתח ה-SSH (הקובץ `.key`) — איתו נכנסים
4. `ssh -i key.key ubuntu@<IP-הציבורי>`

### שלב 2 — העלאת הקוד והתקנה

```bash
# במחשב שלך:
scp -i key.key -r lemontankstream/lemontank-stream ubuntu@<IP>:~/

# בשרת:
cd ~/lemontank-stream
sudo bash deploy/bootstrap-free-vm.sh --check   # בדיקה בלבד
sudo bash deploy/bootstrap-free-vm.sh           # התקנה מלאה
```

הסקריפט עושה הכל: Node 22, **swap** (קריטי ב-1GB RAM), משתמש שירות לא-root,
התקנה, סודות, מסד, בנייה, שירות systemd, ו-cloudflared.

### שלב 3 — דומיין ומנהרה (הקסם האמיתי)

```bash
cloudflared tunnel login                       # פותח דפדפן
cloudflared tunnel create lemontank            # מחזיר TUNNEL-ID
sudo cp ~/lemontank-stream/deploy/cloudflared-config.yml /etc/cloudflared/config.yml
sudo nano /etc/cloudflared/config.yml          # החלף <TUNNEL-ID> ו-<domain>
sudo cloudflared service install
sudo systemctl enable --now cloudflared
```

**מה זה נותן:** השרת יוזם חיבור **יוצא** ל-Cloudflare. אין פורט פתוח, אין IP
שאפשר לסרוק, וה-HTTPS חינם. סורק שיסרוק את כל האינטרנט לא ימצא אותך — כי אין
מה למצוא.

### שלב 4 — הפעלת החמקן

```bash
cd ~/lemontankstream/lemontank-stream
node scripts/stealth.mjs on drop
node scripts/stealth.mjs token     # ← הסימן הסודי
```

את הסימן מדביקים ב-Cloudflare → **Rules → Transform Rules → Add header**:
`x-lt-origin: <הסימן>`. מאותו רגע: רק תעבורה שעוברת דרך Cloudflare receives
שירות; כל השאר מקבל התעלמות.

### שלב 5 — הגדרות אחרונות

```env
APP_URL="https://your-domain"
COOKIE_SECURE="true"
```
```bash
sudo systemctl restart lemontank
curl -I https://your-domain              # אמור לעבוד (200)
curl -I http://<IP-הציבורי>:3000         # אמור לא לענות
```

### שלב 6 — וידאו: Cloudflare R2 (חינם, ובלי עלות העברה)

זו הנקודה שקובעת אם האתר ישרוד כלכלית. **אל תשמור קבצי וידאו על דיסק השרת.**

| | R2 Free |
|---|---|
| אחסון | 10GB |
| **תעבורה יוצאת** | **חינם — תמיד, בכל נפח** ← זה מה שהורג אתרי וידאו בכל מקום אחר |
| כתיבות | מיליון בקשות בחודש |

מעבר ל-10GB: $0.015 ל-GB-חודש — כלומר 100GB וידאו = ~$1.35 בחודש, **בלי עלות
העברה**. העלה ל-R2 ושמור ב-`stream_url` של הכותר את הכתובת החיצונית.

## 7. אזהרות — הדברים שאף מדריך לא אומר

1. **זכויות יוצרים = סיכון החסימה האמיתי.** כל ספק חינמי (ו-Oracle במיוחד)
   ישעה חשבון בגלל תלונת DMCA. זה לא עניין של אבטחה — זו מדיניות. שרת בתשלום
   גם הוא יחסם, אבל לפחות לא תאבד את החשבון כולו.
2. **אין SLA בחינם.** Oracle לא מתחייבת לזמן פעילות, ומשחזרת מופעים לא פעילים.
3. **גיבוי זה באחריותך.** הרץ `node scripts/backup-offsite.mjs` (דורש `BACKUP_KEY`)
   — ולא על אותו דיסק.
4. **תעבורה יוצאת בגוגל: 1GB/חודש.** אם בחרת ב-GCP — הווידאו **חייב** להיות ב-R2.
5. **ה-10TB של Oracle הם על החשבון**, לא על מופע בודד. אתר וידאו קטן לא יתקרב לזה.
