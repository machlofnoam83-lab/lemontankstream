# 🍋 LemonTank Stream

פלטפורמת סטרימינג ישראלית לסרטים וסדרות — **ממשק עברי מלא (RTL)**, שני מסלולי מנוי
(**חינם** ו**פלוס**), ופאנל ניהול שמחליט לכל כותר ולכל פרק אם הוא חינם או פלוס.

נבנה עם Next.js 15 (App Router) + React 19 + Tailwind 4 + TypeScript, על מסד נתונים
SQLite מובנה ב-Node (`node:sqlite`) — **בלי עלויות, בלי שרת DB, בלי תלויות נייטיביות**.

---

## ⚡ התחלה מהירה (3 דקות)

```bash
# 1. התקנת תלויות
npm install

# 2. הפקת סודות + כתיבה ל-.env.local (כולל סיסמת מנהל)
node scripts/gen-secrets.mjs --write

# 3. יצירת המסד + נתוני דמו (כותרים, פרקים, ערוצי לייב, קופונים, משתמשים)
node scripts/seed.mjs

# 4. הרצה
npm run dev          # פיתוח → http://localhost:3000
# או
npm run build && npm run start
```

## 🎬 מה יש במערכת

### צד הצופה
- **בית** עם הירו, שורות אוספים, "ממשיכים לצפות", עשרת הגדולים והמלצות אישיות
- **סרטים / סדרות / חדש / פופולרי / ז'אנרים / חיפוש** עם סינון, מיון ועמודים
- **עמוד כותר**: פרטים, עונות ופרקים, דירוגים, ביקורות, תגובות, רשימות ו-JSON-LD ל-SEO
- **נגן** עם המשך צפייה מדויק, דילוג על פתיח, בחירת איכות, כתוביות ומסך מלא
- **שידור חי** לפי קטגוריות, עם לוח שידורים (EPG) ונעילה למסלול
- **אזור אישי**: סקירה, אבטחה (סיסמה + 2FA + מכשירים), פרופילים (עד 5 בפלוס),
  חיוב וחשבוניות, היסטוריית צפייה ופרטיות (ייצוא/מחיקה לפי GDPR)
- **דפי תוכן**: מנויים ומחירים, רשימה שלי, התראות, תמיכה, מסמכים משפטיים

### צד הניהול (`/admin`)
| עמוד | מה עושים בו |
|---|---|
| לוח בקרה | מדדים, גרפי הרשמות, פיד ביקורת, פעולות מהירות |
| כותרים | יצירה, עריכה, פרסום, מחיקה ומחיקת-גורף; **קביעת חינם/פלוס** |
| פרקים | העלאת וידאו ותמונה לכל פרק, סימוני פתיח, מצב פרסום והרשאה |
| משתמשים | תפקידים (צופה → עורך → מנהל → בעלים), השעיה, ניתוק מכשירים |
| מנויים | מעקב MRR, מע״מ, הארכה/ביטול/הענקה ידנית |
| קופונים | אחוז / סכום / ימי מתנה, מגבלות מימוש ותפוגה |
| מסלולים | מחירים, איכות, מסכים במקביל, הורדות ופרסומות |
| ז'אנרים / אוספים / קמפיינים / לייב | ניהול תוכן ותצוגה |
| פיצ'רים | ~70 מתגי מערכת עם תפוצה באחוזים (A/B) |
| אנליטיקה | צפיות יומיות, זמן צפייה, שיעור השלמה, חיפושים מובילים |
| ייבוא | העלאת קטלוג מ-JSON + היסטוריית עבודות ייבוא |
| אבטחה / ביקורת / בריאות | אירועי אבטחה, יומן מלא (מי/מה/מתי/IP), בדיקות תצורה ותחזוקה |

### הרשאות: חינם מול פלוס
- לכל **כותר** ולכל **עונה/פרק** יש שדה `plan_access`: `free` / `plus` / `inherit` (בירושה).
- `inherit` בפרק → נופל להרשאה של העונה → של הסדרה. צוות (עורך ומעלה) רואה הכול לצורכי בדיקה.
- **האכיפה בשרת**, לא בממשק: גם מי שינסה לשלוף כתובת וידאו ישירות יקבל `402 PLAN_REQUIRED`.

## 🔒 אבטחה

| שכבה | מה נעשה |
|---|---|
| סיסמאות | `scrypt` (N=2¹⁵, r=8, p=1) + מלח ייחודי + השוואה בזמן קבוע |
| סשנים | טוקן 256-bit אקראי; ב-DB נשמר **רק ה-SHA-256**. סיבוב טוקן, ניתוק מכשירים, גילוי סשנים |
| CSRF | Double-submit cookie + HMAC עם סוד נפרד + בדיקת Origin/Referer |
| XSS | React escaping + סניטציה + CSP עם nonce לכל בקשה (`strict-dynamic`) |
| SQL Injection | `prepare()` עם placeholders בכל שאילתה + שכבת בדיקה על SQL דינמי |
| Header hardening | HSTS, nosniff, Referrer-Policy, Permissions-Policy, COOP/CORP, `frame-ancestors` |
| הגבלת קצב | 8 התחברויות / 5 דק' לכל IP, 5 הרשמות / שעה, 240 בקשות API / דקה |
| נעילת חשבון | 5 כשלים → 60 שניות, 12 → 30 דקות, 20 → שעתיים |
| 2FA | TOTP (RFC 6238) + קודי גיבוי; הסוד נשמר מוצפן ב-AES-256-GCM |
| העלאות | בדיקת magic-bytes, סוגים מותרים, SHA-256, שם קובץ שנוצר בשרת |
| מדיה | אין גישה לקבצים בנתיב סטטי; הכול דרך `/api/media/[id]` עם Range ובקרת הרשאה |
| פרטיות | IP נשמר מגובב (hash), ייצוא ומחיקה עצמית, ביקורת ללא מחיקה |
| ביקורת | כל פעולה רגישה → `audit_log`; אירועי אבטחה → `security_events` |

## 🗄️ מסד הנתונים — ובחירת ה"חינם"

המערכת רצה על **SQLite המובנה ב-Node** (`node:sqlite`) — בלי התקנה ובלי עלות:

- קובץ אחד: `./data/lemontank.db` (WAL, `foreign_keys=ON`, `secure_delete=ON`)
- ~45 טבלאות + חיפוש מלא FTS5 בעברית, JSON1, טרנזקציות
- אין הגבלת גודל או מספר שורות מלבד הדיסק
- בונוס: אפשר לגבות בהעתקת קובץ אחד (`/api/export?type=backup` מייצא JSON מלא)

**רוצה Postgres חינמי?** הסכימה מוכנה ב-`sql/schema.postgres.sql` ל-
[Neon](https://neon.tech) / [Supabase](https://supabase.com) (חינם, 0.5GB).
צריך להוסיף מתאם `pg` קטן ב-`src/lib/db.ts` — כל שאר הקוד לא משתנה (ראו `DEPLOY.md`).

## 🧪 בדיקות

```bash
node scripts/seed.mjs          # הבדיקות דורשות מסד מזורזע
npm run build && npm run start # או npm run dev
npm test                       # 15 בדיקות אינטגרציה מול ה-API
```

הבדיקות מכסות: חוזי API, כותרות אבטחה ו-CSP, דחיית CSRF, חסימת path traversal,
RBAC (משתמש רגיל מול מנהל), נעילת תוכן פלוס, וחוזה התשובה האחיד
`{ok:true,data}` / `{ok:false,error{code,message}}`.

```bash
npm run typecheck              # TypeScript strict — 0 שגיאות
test $TEST_BASE_URL || TEST_BASE_URL=http://localhost:3000 npm test
```
