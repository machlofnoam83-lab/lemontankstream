# 🚀 הרצה במחשב — צעד אחר צעד (ווינדוס)

> ## ⚠️ קרא את זה קודם — זה החלק שמבלבל את כולם
>
> **`localhost` הוא המחשב שלך. לא שלי.** אם אתה לוחץ על קישור `localhost:3000`
> בצ'אט (או בכל מקום) **לפני** שהרצת את האתר — הדפדפן יחזיר
> `ERR_CONNECTION_REFUSED`, וזה בדיוק מה שהוא אמור לעשות: אין שם כלום.
>
> **סדר הפעולות הנכון:**
> 1. מריצים את האתר במחשב: **קליק כפול על `START-HERE-WINDOWS.cmd`**
>    (או `npm run start`) — נפתח חלון שרת.
> 2. **רק אז** גולשים ל-`http://localhost:3000`.
> 3. **לא סוגרים את חלון השרת.** הוא האתר. סגרת = האתר נפל.
>
> **רוצה לראות את האתר בלי להריץ כלום אצלך?** השתמש בקישור הענן ששלחתי בצ'אט
> (משהו כמו `https://3000-….e2b.app`) — הוא לא תלוי במחשב שלך בכלל.

מדריך מדויק: בכל שלב כתוב **מה אתה מקליד** ו**מה אתה אמור לראות**. אם שלב לא
נראה כמו המתואר — עצור, והרץ את מה שכתוב ב־"אם משהו לא בסדר" בסוף.

**זמן:** 5–8 דקות בפעם הראשונה (רוב הזמן זה ההתקנה והבנייה). בפעמים הבאות — 5 שניות.

## שלב 0 — Node.js מותקן? (פעם אחת בחיים)

פותחים **Command Prompt** (מקש Windows → כותבים `cmd` → Enter) ומקלידים:

```cmd
node -v
```

**מה אמור להופיע:** משהו כמו `v24.19.0` — כל מספר מ-**22.13** ומעלה טוב.

| מה קרה | מה לעשות |
|---|---|
| `v24.19.0` (או 22.13+) | ✅ המשך לשלב 1 |
| `v18.x` / `v20.x` | היכנס ל-[nodejs.org](https://nodejs.org) → כפתור **LTS** → התקן → **סגור ופתח חלון cmd חדש** |
| `'node' is not recognized` | Node לא מותקן — אותו דבר: הורד LTS והתקן, ואז חלון חדש |
| `bash is not recognized` | זה בסדר — בווינדוס אין bash. במדריך הזה אין צורך בו |

## שלב 2 — מעדכנים לגרסה האחרונה

> **קליק כפול על `UPDATE-WINDOWS.cmd`** עושה את כל השלב הזה לבד — וגם את שלב 3
> (הכנה ובנייה). אם הקובץ הזה עוד לא קיים בתיקייה שלך, הרץ קודם את שלוש
> הפקודות למטה — הן מושכות אותו, ומכאן והלאה זה רק קליק.

```cmd
git fetch origin
git checkout arena/01a0d612-lemontankstream
git pull --ff-only origin arena/01a0d612-lemontankstream
```

**למה לא סתם `git pull`:** גרסה חדשה של האתר נמצאת בענף
`arena/01a0d612-lemontankstream`. אם התיקייה שלך עומדת על ענף אחר (למשל `main`),
הוא פשוט לא יראה את העדכונים. שלוש השורות למעלה מעבירות אותך לענף הנכון.

**מה אמור להופיע:** `Already up to date.` או רשימת קבצים שהתעדכנו.

מכאן והלאה — **`UPDATE-WINDOWS.cmd` בקליק כפול** (או `npm run update`), והוא כבר
עושה לבד: מוריד → מתקין → ממלא את המסד → בונה.

> ✅ **בטוח לחלוטין לתוכן שלך:** המסד (`data/`), הסודות (`.env.local`) והגיבויים
> (`backups/`) לא מנוהלים ב-Git, ולכן `git pull` לא נוגע בהם.

| מה קרה | מה לעשות |
|---|---|
| `Already up to date.` | ✅ המשך |
| רשימת קבצים + `Fast-forward` | ✅ עודכן — המשך |
| `not a git repository` | הורדת ZIP — אין מה לעדכן, המשך לשלב 3 |
| `error: Your local changes…` | הרץ `git stash` ואז `git pull` ואז `git stash pop` |

## שלב 5 — מדליקים את האתר

**הדרך הקלה (מומלץ):** קליק כפול על **`START-HERE-WINDOWS.cmd`**.
הוא מכין הכל, בוחר פורט פנוי, **פותח חלון שרת נפרד** בשם `LemonTank Server`,
ממתין שהאתר יעלה, **פותח את הדפדפן לבד**, ומדפיס לך את הכתובת. אתה לא צריך להקליד כלום.

**הדרך הידנית (מומלצת במיוחד — זו שגם מחזירה את האתר לבד אם הוא נופל):**

```cmd
npm run watchdog
```

זה מרים את האתר **ומשגיח עליו**: דופק כל 10 שניות, ואם התהליך נפל או שהחלון
נסגר בטעות — הוא מחזיר אותו לבד, בלי שתגע בכלום.

```cmd
npm run start
```
(זו ההרצה הרגילה — בלי השגחה. אם החלון נסגר, האתר נופל.)

**מה אמור להופיע:**

```
╭──────────────────────────────────────────────────────────────╮
│  🍋 LemonTank Stream — שרת מאובטח                            │
╰──────────────────────────────────────────────────────────────╯
   🌐  האתר:              http://localhost:3000
   📱  מהטלפון/מהרשת הביתית:  http://192.168.1.20:3000
   🛡️   מצב אבטחה:        ENFORCE (חסימה פעילה)
```

🔴 **קריטי:** החלון הזה **הוא** האתר. כל עוד הוא פתוח — האתר חי.
סגרת = האתר נפל (ואתה תקבל `ERR_CONNECTION_REFUSED` בדפדפן).
לעצירה מסודרת: `Ctrl + C` בחלון הזה.

**חלון שני** (השאר את הראשון פתוח!) — פתח את הדפדפן:

```
http://localhost:3000
```

## שלב 6 — נכנסים ומוסיפים תוכן

1. גלוש ל-**http://localhost:3000/login**
2. דוא"ל: `admin@lemontank.local` · סיסמה: `ChangeMe-Admin-2026!`
   *(אם החלפת סיסמה בעבר — היא זו שב-`.env.local`, שורה `SEED_ADMIN_PASSWORD`)*
3. הוספת סרט/סדרה: **http://localhost:3000/admin/titles/new**
   - סרט → מלא פרטים → העלה קובץ וידאו
   - סדרה → צור את הסדרה → "ניהול פרקים" → העלה פרק-פרק
   - שידור חי → **http://localhost:3000/admin/live**
4. שכבת החינם/פלוס לכל כותר ולכל פרק — בפאנל, לפי בחירה שלך.

**בדיקה שהכל עובד:** אחרי שהעלית כותר, גלוש ל-`/movies` — הוא אמור להופיע.

## שלב 7 — רוצה שטלפון/מחשב אחר ייכנס? (אותה רשת Wi-Fi)

1. בחלון של `npm run start` יש שורה: `📱 מהטלפון/מהרשת הביתית: http://192.168.x.x:3000`
2. הקלד **בדיוק את הכתובת הזו** בטלפון (באותה רשת Wi-Fi)
3. אם ווינדוס שואל על פיירוול בהרצה הראשונה → **Allow** (רשת פרטית)

⚠️ זה HTTP לא מוצפן — מתאים לרשת ביתית בלבד. **לא** לחשוף לאינטרנט ככה.

## אם משהו לא בסדר — לפי ההודעה שקיבלת

| מה רואים | המשמעות | הפתרון |
|---|---|---|
| `ERR_CONNECTION_REFUSED` **ולא הרצת כלום** | `localhost` מצביע למחשב שלך, ואין בו שרת | הרץ קליק כפול על `START-HERE-WINDOWS.cmd` — ואז הדפדפן ייפתח לבד |
| `ERR_CONNECTION_REFUSED` **גם אחרי שהרצת** | החלון נסגר, או שהמחשב הופעל מחדש | מכאן והלאה זה לא יקרה: `npm run watchdog` מרים את האתר **ומחזיר אותו לבד** אם הוא נופל. לקום לבד עם המחשב: `npm run autostart` (פעם אחת) |
| `ERR_CONNECTION_REFUSED` **והשרת רץ** | פורט אחר, פרוקסי/VPN, או אנטי-וירוס | `npm run doctor` → סעיף 6 יראה לך מה לבדוק (127.0.0.1 במקום localhost, חלון פרטי, כיבוי פרוקסי) |
| `ERR_ADDRESS_INVALID` | גלשת ל-`0.0.0.0:3000` | גלוש ל-`http://localhost:3000` |
| `'npm' is not recognized` | Node לא מותקן / חלון לא נפתח מחדש | התקן LTS מ-nodejs.org → חלון **חדש** של cmd |
| `✗ בנייה נכשל` | שגיאה אמיתית בהרצת הבנייה | הרץ `npm run build` לבד והעתק לי את 20 השורות האחרונות |
| `EADDRINUSE` | הפורט תפוס | סגור את החלון הישן, או `set PORT=3001 && npm run start` |
| הדף נטען אבל בלי עיצוב | הקובץ CSS לא נטען | `Ctrl + F5` (רענון מלא) |
| `גישה נחסמה ע"י מערכת האבטחה` | המלכודות חסמו אותך (למשל רענון מהיר מדי) | המתן דקה; לבדוק מי נחסם: `npm run security:status` |
| עברית מוצגת כג'יבריש ב-cmd | קידוד המסוף | הלאנצ'ר מטפל בזה; ידנית: `chcp 65001` |
| רוצה להתחיל תוכן מאפס | — | `node scripts/seed.mjs --reset` |

**הפקודה הכי שימושית כשלא ברור מה קורה:** `npm run doctor` — היא אומרת בעברית
פשוטה מה חסר ומה לעשות, ובפועל מרימה את השרת כדי לראות אם הוא באמת עולה.
